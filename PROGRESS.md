- PPTX deck system: `decks/theme.js` (in the repo) implements the "Ocean Gradient" palette + Cambria/Calibri typography + a box-chain/twobox/stat/circles/quote/table diagram library. Exports: `newDeck`, `addTitleSlide`, `addContentSlide`, `addRecapSlide`, `COLOR`. Each day's deck is generated by a small `decks/dayNN-deck.js` script that calls these helpers and writes to `dayNN/dayNN-slides.pptx` — cheap to extend to Days 7+ by following the same pattern (see `decks/day01-deck.js` through `day06-deck.js` as references).
